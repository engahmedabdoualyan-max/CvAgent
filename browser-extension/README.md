# 🧩 إضافة CvAgent للمتصفح — ON/OFF (v2.0)

وكيل ملء طلبات التوظيف **جوه متصفحك** — من غير بايثون ولا تيرمنال.

## ✨ الجديد في v2.0

| الميزة | الوصف |
|---|---|
| 🛡 **كشف الكابتشا و OTP** | لو ظهر Captcha أو رمز تحقق — الوكيل يقف ويسيبك تحلها وترجع تدوس الزرار |
| ⌨️ **كتابة بشرية** | حرف حرف بسرعات عشوائية ووقفات طبيعية — زي إيد بشرية |
| 🕳 **اختراق Shadow DOM** | بيوصلك لخانات مخفية جوه مكونات معزولة (Workday بيستخدمها كتير) |
| 📴 **وضع أوفلاين** | لو الـ API وقع: البيانات الأساسية (اسم، إيميل، تليفون، عنوان) بتتملأ محلياً |
| ⚠️ **فحص الخانات الحساسة** | بينبهك لو الصفحة بتطلب بيانات مفرطة (راتب، ديانة، رقم قومي...) |
| 👔 **4 شخصيات إجابة** | Manager / Technical / Executive / Balanced — بتغير نبرة الأسئلة المقالية |
| 📋 **سجل التقديمات** | كل تقديم بيتسجل تلقائياً + تصدير CSV بضغطة |
| ⏭️ **Next يدوي أو تلقائي** | افتراضياً انت بتدوس Next بنفسك (أأمن) — وتقدر تفعّل التلقائي |

## 📥 التثبيت (مرة واحدة — دقيقتين)

1. افتح Chrome / Edge / Chromium
2. اكتب في شريط العنوان: `chrome://extensions`
3. فعّل **Developer mode** (الزرار فوق يمين)
4. دوس **Load unpacked**
5. اختار فولدر `browser-extension` ده كله
6. هتلاقي أيقونة 🤖 ظهرت جنب شريط العنوان — دوس عليها 📌 عشان تثبت

## ⚙️ الإعداد (من أيقونة الإضافة)

| الخطوة | التفاصيل |
|---|---|
| **1. مفتاح Groq** | من [console.groq.com/keys](https://console.groq.com/keys) — انسخه وحطه في الخانة (بيتخزن في متصفحك بس) |
| **2. ملف profile.json** | ارفع نفس ملف بياناتك (موجود في `job-agent/profile.json`) |
| **3. شغّل الزرار** | فعّل المفتاح الأخضر ON |

## 🚀 الاستخدام اليومي

1. افتح صفحة التقديم (Workday أو أي موقع وظائف)
2. هتلاقي **زرار برتقالي عايم** تحت يمين: `🤖 CvAgent — Fill this page`
3. دوس عليه → هتتملأ الخانات قدامك مباشرة (نصوص، قوائم منسدلة، دوائر اختيار، تقويم التواريخ)
4. لو الصفحة فيها زرار Next هيدوسه — في الصفحة الجديدة دوس الزرار تاني
5. **لما يوصل لزرار Submit هيقف ويقولك** — راجع واضغط بنفسك ✅

## 🧠 إزاي بيشتغل؟

```
أنت في الصفحة → تدوس الزرار البرتقالي
   ↓
الإضافة بتقرأ كل خانة ظاهرة (نص، قائمة، سؤال فرز، تقويم)
   ↓
تبعتها + ملف بياناتك لـ Groq AI (llama-3.3-70b)
   ↓
الـ AI يرجع خريطة: "الخانة دي ← اكتب كذا / اختار كذا"
   ↓
الإضافة تنفذ قدامك: تكتب، تفتح القوائم وتختار، تدوس على التقويم
```

## 🔒 الخصوصية والأمان

- مفتاح الـ API وملف بياناتك **متخزنين في متصفحك فقط** (chrome.storage) — مش بيروحوا أي سيرفر غير Groq
- **رقم الإقامة**: استخدم نسخة `profile.json` من غير إقامة، أو اعمل `profile.local.json` خاص بك
- الوكيل **مش بيدوس Submit أبداً** — المراجعة النهائية بيدك دايماً
- الكود مفتوح بالكامل — راجعه زي ما تحب

## ❓ مشاكل شائعة

| المشكلة | الحل |
|---|---|
| الزرار البرتقالي مش ظاهر | حدّث الصفحة (F5) بعد تشغيل ON |
| "No API key set" | افتح الإضافة وحط المفتاح |
| "Rate limited" | استنى دقيقة — Groq المجاني ليه حدود |
| خانة معينة متملتتش | دوس الزرار تاني — بيتخطى المملوء |
