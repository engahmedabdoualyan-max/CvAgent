# 🦊 CvAgent لفايرفوكس — نسخة Firefox

نفس الوكيل بالكامل، بس بملف manifest متوافق مع فايرفوكس (Firefox بيستخدم `background.scripts` مش `service_worker`).

## 📥 التثبيت المؤقت (أسرع طريقة)

1. افتح فايرفوكس واكتب في شريط العنوان: `about:debugging#/runtime/this-firefox`
2. دوس **Load Temporary Add-on...**
3. اختار ملف **`manifest.json`** جوه الفولدر ده
4. هتلاقي أيقونة 🤖 ظهرت

### ⚠️ خطوة إلزامية بعد التثبيت في فايرفوكس
فايرفوكس بيطلب إذنك يدوياً للسماح للإضافة تشتغل على المواقع:
1. افتح `about:addons`
2. Extensions → **CvAgent** → تاب **Permissions**
3. فعّل **Access your data for all websites** ✅
4. لو ظهرت رسالة إذن أثناء الاستخدام — وافق عليها

بدون الإذن ده الزرار البرتقالي مش هيظهر في الصفحات.

## ⚠️ ملاحظات مهمة لفايرفوكس

| النقطة | التفاصيل |
|---|---|
| **مؤقت** | التثبيت المؤقت بيمسح نفسه لما تقفل فايرفوكس — هتعيد الخطوات في كل مرة (طبيعي في وضع المطورين) |
| **دائم** | عشان يفضل معاك: انشره على [addons.mozilla.org](https://addons.mozilla.org/developers/) مجاناً (بعد توقيع الملف)، أو **استخدم Chrome/Edge** بالنسخة العادية |
| **🎤 الصوت** | Voice-to-form مش مدعوم في فايرفوكس (تقنية المتصفح نفسها) — كل باقي الـ30 ميزة شغالة |
| **الأذونات** | لو زرار "املأ الصفحة" قالك خطأ — افتح Permissions وفعّل الوصول للمواقع |

## ✅ المتصفحات المدعومة

| المتصفح | الفولدر | الحالة |
|---|---|---|
| Chrome / Edge / Brave / Opera | `browser-extension/` | ✅ كامل + دائم |
| Firefox | `firefox-extension/` | ✅ كامل (مؤقت التثبيت، بدون voice) |
